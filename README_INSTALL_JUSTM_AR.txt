مشروع Just-M كامل مع سكربت إنشاء قاعدة البيانات

1) فك ضغط المشروع على بيئة اختبار أولًا.
2) أنشئ نسخة احتياطية من قاعدة البيانات الحالية قبل أي استيراد.
3) استورد inc/Databases/JUSTM_DATABASE_INSTALL.sql عبر phpMyAdmin أو عميل MariaDB.
4) راجع بيانات التهيئة التجريبية الموجودة في inc/Databases/createDatabase.sql، خصوصًا حساب المستخدم والعنوان والهاتف، قبل الاستخدام الفعلي.
5) السكربت ينشئ الجداول القديمة (من ملف المشروع) وجداول الأستاذ العام والتخصيصات وتسوية عهدة المندوب.
6) لم يتضمن أرشيف المشروع الأصلي DDL الأصلي لجداول الأستاذ العام؛ أُضيفت بنية متوافقة مع الحقول التي يستخدمها كود المحاسبة الحالي. لذلك يجب مراجعة البنية على نسخة اختبار قبل الإنتاج.
7) لا يحتوي السكربت على شجرة حسابات أو ربط حسابات افتراضي؛ لا بد أن يحدد المحاسب الحسابات المعتمدة ويضبط account_settings وcash_boxes وpayment_method_accounts.
8) ملفات الإجراءات المخزنة الأصلية ما زالت في inc/Databases/*.sql. بعض الملفات تحتوي نسخًا مختلفة من الإجراءات المتشابهة؛ لا تشغّلها كلها عشوائيًا. راجع الإجراء الذي يستدعيه الكود واختبره قبل تثبيته.
9) لم يتم الاتصال بقاعدة MariaDB فعلية لاختبار الاستيراد أو تنفيذ ترحيل إنتاجي. فحص الصياغة لا يثبت سلامة التكامل.

مهم: قاعدة البيانات الافتراضية في السكربت اسمها cptest. عدّل اسمها في أول سطرين عند الحاجة قبل الاستيراد.

ملاحظة المحاسبة الجديدة:
راجع docs/RELEASE_IMPLEMENTATION_STATUS_AR.md قبل أي تثبيت مالي.
Migration مواءمة الأستاذ العام: inc/Databases/migrations/PHASE15_ACCOUNTING_SCHEMA_ALIGNMENT.sql
Seed دليل الحسابات (بعد مراجعة القاعدة): inc/Databases/seeds/CHART_OF_ACCOUNTS_SEED.sql
لا تشغل ملفات المحاسبة على الإنتاج قبل Backup واختبارها على قاعدة منفصلة وإعداد ربط الصناديق وطرق الدفع بمعرفات الفروع الفعلية.
