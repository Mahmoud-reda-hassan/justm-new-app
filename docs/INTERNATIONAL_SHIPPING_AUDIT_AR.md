# تدقيق حالة الشحن الدولي في Just-M

**التاريخ:** 2026-11-11  
**الفرع:** `rebuild-v2`  
**الحالة:** غير منفذ / غير مكتمل في المرجع القديم المتاح  
**القرار:** عدم إنشاء تنفيذ دولي تخميني قبل استعادة مرجع تشغيلي أو اعتماد متطلبات واضحة.

## 1. هدف المراجعة

التحقق مما إذا كان الشحن الدولي في النظام القديم ميزة تشغيلية مكتملة، أم مجرد مدخل وصلاحيات دون شاشة وعمليات فعلية، وتحديد ما يجوز تنفيذه في النسخة الجديدة دون اختراع قواعد عمل.

## 2. ما تم التحقق منه في `main`

| المصدر | نتيجة الفحص |
|---|---|
| `inc/routes/admin_router.php` | يوجد مسار باسم `International-Shipping` وعنوان إعدادات الشحن الدولي، ويشير إلى View بالاسم نفسه. |
| `inc/Views/International-Shipping.php` | الملف غير موجود في شجرة الملفات التي تمت مراجعتها (GitHub أعاد 404). |
| `inc/Views/Countries.php` | الواجهة المشتركة للدول والمحافظات والمدن والشحن المحلي، وليست واجهة دولية. |
| `inc/Api.php` | عمليات المناطق التي أمكن تتبعها تخص `Local-Shipping` فقط؛ لم نعثر على CRUD أو API للشحن الدولي. |
| `inc/Classes/Zones_tbl.php` | الكلاس يدير مناطق الشحن المحلي وربطها بالمدن، ورسومها ومدتها ومخزنها ونوعها. |
| `inc/Databases/createDatabase.sql` | يحتوي `shipping_type` و`zones` المحليين؛ لم يظهر ضمن البنية التي تمت مراجعتها نموذج مستقل لتعرفة دولية أو وجهة دولية أو ناقل دولي. |

## 3. التمييز بين المحلي والدولي

الحقول الموجودة في `zones` القديمة تشمل اسم المنطقة، رسوم الشحن، الحد الأدنى، أقصى مدة توصيل، نوع الشحن، ومخزنًا مرتبطًا، مع ربط المدن بالمنطقة.

هذه الحقول جزء من إعداد الشحن المحلي. وجود حقل `SHIPPING_TYPE` أو قيم مثل داخلي/خارجي لا يثبت وحده وجود دورة شحن دولي، ولا يوضح كيفية تحديد الدولة المستقبلة أو احتساب السعر الدولي.

وفي `rebuild-v2`، شاشة `admin.shipping.zones` هي شاشة مناطق محلية مرتبطة بمدن ومخازن بيع مباشر. لا ينبغي اعتبارها تنفيذًا للشحن الدولي.

## 4. ما لم يثبت وجوده

لم نعثر في الملفات التي تمت مراجعتها على تنفيذ موثوق لأي من الآتي:
- تعريف دول الوجهة ونطاقات التغطية الدولية.
- تعرفة دولية حسب الدولة أو المنطقة أو الوزن أو الحجم.
- شركات الشحن أو الناقلون الدوليون وخدماتهم.
- قواعد الجمارك أو الرسوم الإضافية أو التأمين.
- العملات والتحويل أو طريقة تسوية تكلفة الشحن.
- حساب السعر الدولي داخل أمر البيع أو تتبع الشحنة الدولية.
- واجهة تشغيل أو صلاحيات CRUD مرتبطة ببيانات دولية فعلية.

**تنبيه:** عدم العثور على هذه العناصر في شجرة `main` التي تمت مراجعتها لا يثبت عدم وجودها في نسخة احتياطية أخرى أو نظام خارجي؛ يلزم فحص أي مصدر إضافي قبل اعتماد النتيجة نهائيًا على مستوى تاريخ المشروع كله.

## 5. القرار المعتمد للنسخة الجديدة

1. إبقاء الدول والمحافظات والمدن ومناطق الشحن المحلي كوظائف منفصلة.
2. عدم تحويل `shipping_type` المحلي إلى نظام دولي.
3. عدم إضافة جداول أو حقول أو أسعار أو قواعد دولية افتراضية.
4. عدم إظهار أن الشحن الدولي مكتمل أو قابل للاستخدام في النسخة الجديدة.
5. عند استعادة ملفات أو Backup أقدم، تتم مراجعتها ومقارنتها قبل تحديد نطاق التنفيذ.
6. أي قواعد دولية غير موجودة في مرجع موثوق تحتاج اعتمادًا وظيفيًا قبل برمجتها.

## 6. الحد الأدنى المطلوب لاستكمال الميزة مستقبلًا

قبل التطوير يجب توفير مرجع أو قرار يحدد:
- الدول والوجهات التي يتم الشحن إليها.
- طريقة تقسيم مناطق التغطية الدولية.
- أساس حساب التكلفة: دولة/منطقة، وزن، حجم، أو تعاقد مع ناقل.
- الناقلون والخدمات والمدة المتوقعة.
- الرسوم الإضافية والجمارك والتأمين، إن وجدت، ومن يتحملها.
- العملة وطريقة عرض السعر والتحصيل.
- موضع اختيار الشحن الدولي في أمر البيع ودورة تجهيز وتسليم الطلب.
- الصلاحيات والأدوار المسؤولة عن الإعداد والتشغيل.

## 7. مراجع الملفات

- `main:inc/routes/admin_router.php`
- `main:inc/Views/Countries.php`
- `main:inc/Classes/Zones_tbl.php`
- `main:inc/Api.php`
- `main:inc/Databases/createDatabase.sql`
- `main:inc/Views/International-Shipping.php` — غير موجود في الشجرة التي تمت مراجعتها.

## 8. أثر المراجعة على التنفيذ

هذه وثيقة تدقيق وتحديد نطاق فقط. لم يتم تشغيل migrations، أو تعديل قاعدة بيانات فعلية، أو دمج الفرع، أو نشر النظام بسبب هذه المراجعة.
