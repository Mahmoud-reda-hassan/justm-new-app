# إعداد البريد الإلكتروني الآمن

تم توحيد إرسال رمز استعادة كلمة المرور في `inc/Classes/Mailer.php` باستخدام PHPMailer الموجود داخل المشروع.

لا توجد بيانات دخول SMTP داخل ملفات PHP. يقرأ المرسل الإعدادات من متغيرات بيئة الخادم أو الثوابت المعرفة قبل تحميله:

| متغير البيئة | مثال/القيمة |
|---|---|
| `JUSTM_SMTP_HOST` | عنوان SMTP من مزود البريد |
| `JUSTM_SMTP_PORT` | `587` مع TLS أو `465` مع SSL |
| `JUSTM_SMTP_USERNAME` | حساب الإرسال |
| `JUSTM_SMTP_PASSWORD` | كلمة مرور التطبيق/SMTP |
| `JUSTM_SMTP_FROM_EMAIL` | عنوان المرسل المعتمد |
| `JUSTM_SMTP_FROM_NAME` | `Just-M` |
| `JUSTM_SMTP_ENCRYPTION` | `tls` أو `ssl` أو `none` |

إذا لم تضبط الإعدادات، يعيد المرسل `false` ويسجل رسالة عامة دون كشف كلمة المرور. يجب ضبط المتغيرات في بيئة IIS/Plesk ثم اختبار إرسال حقيقي من صفحة استعادة كلمة المرور.
