# وحدة تهيئة Just-M

## الهدف

تجهيز قاعدة بيانات نسخة جديدة بطريقة قابلة للتكرار، دون حذف بيانات قائمة أو إنشاء حساب افتراضي معروف.

## المتطلبات

- PHP 8.3 أو أحدث (المستهدف PHP 8.4).
- Composer dependencies مثبتة.
- MariaDB/MySQL مع امتداد `pdo_mysql`، أو SQLite للاختبارات المحلية.
- ضبط `.env` بقيم الاتصال الصحيحة.
- صلاحية `CREATE DATABASE` مطلوبة فقط عند استخدام خيار إنشاء قاعدة البيانات تلقائيًا.

## خطوات التثبيت

1. انسخ `.env.example` إلى `.env` واضبط `APP_KEY` وبيانات اتصال قاعدة البيانات.
2. إذا كانت قاعدة البيانات غير موجودة، نفّذ:
   `php artisan justm:setup --create-database`
   يحتاج مستخدم قاعدة البيانات إلى صلاحية إنشاء قواعد البيانات.
3. إذا كانت قاعدة البيانات موجودة بالفعل، نفّذ:
   `php artisan justm:setup`
4. أنشئ أول مدير من الطرفية:
   `php artisan justm:provision-first-admin`
   أدخل الاسم واسم المستخدم والبريد، ثم كلمة مرور لا تقل عن 12 حرفًا وتأكيدها. كلمة المرور تُطلب كمدخل مخفي ولا تُقبل كوسيط command-line.

## ماذا تنشئ الوحدة؟

- تنشئ قاعدة البيانات عند طلب ذلك صراحةً، وعلى MySQL/MariaDB فقط.
- تشغّل جميع migrations المسجلة.
- تزرع مجموعة تأسيسية لإدارة المستخدمين ومجموعات الصلاحيات، مرتبطة بمفاتيح الصلاحيات الأحد عشر المعتمدة حاليًا.
- تنشئ أول مدير مرة واحدة فقط، وتربطه بهذه المجموعة المحدودة.

## ما لا تفعله

- لا تحذف قاعدة البيانات أو الجداول أو السجلات القائمة.
- لا تنشئ كلمة مرور أو حسابًا افتراضيًا.
- لا تمنح صلاحيات شاملة أو مالية أو مخزنية.
- لا تنشئ بيانات تجريبية للعملاء أو المنتجات أو الشركات أو الفروع أو المخازن أو المدن أو الحسابات؛ هذه البيانات تنتظر اعتماد وحداتها.
- لا تستورد مستخدمي النظام القديم.

## الأمان وإعادة التشغيل

- تشغيل `justm:setup` مرة أخرى آمن من ناحية البيانات: migrations وseeder قابلان لإعادة التشغيل، ولا يُنشئان مستخدمين.
- أمر أول مدير يرفض التنفيذ بمجرد وجود أي مستخدم، وليس فقط عند وجود مدير.
- لا يوجد مسار ويب عام لإنشاء مدير أو ترقية حساب.
- يجب عدم تشغيل أوامر التهيئة على قاعدة إنتاج أو قاعدة تحتوي بيانات فعلية دون مراجعة وموافقة صريحة.

## الاختبارات

`php artisan test --filter=SetupModuleTest`

تغطي الاختبارات تكرار seeding، وإنشاء مجموعة الصلاحيات المحدودة، وإنشاء أول مدير، ورفض إعادة التهيئة عند وجود مستخدم.
