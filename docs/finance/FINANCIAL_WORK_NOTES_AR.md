# ملاحظات نسخة عمل الترحيل المالي

هذه نسخة عمل منفصلة عن المشروع الأصلي. لم يتم حذف الجداول القديمة أو تعديل قاعدة بيانات فعلية.

## إصلاحات أولية في طبقة المحاسبة الجديدة

1. `inc/Classes/Accounting/JournalManager.php`
   - إصلاح استدعاء `addLine()` في `reverse()` ليتوافق مع توقيع الدالة الحالي (مصفوفة واحدة).
   - تصحيح أعمدة التحقق من الشريك: المورد `SUP_ID`، والمندوب/المسوق/الموظف `USER_ID` وفق `createDatabase.sql`.
2. `inc/Classes/Accounting/AccountingEvents.php`
   - احتساب قيمة البيع المرتجع من `RETURNED_QTY` بدل `DELIVERED_QTY`.
   - فحص المبالغ كقيم رقمية بدل تحويلها إلى عدد صحيح.
   - تصحيح جلب تحصيل البيع المباشر ليستخدم رقم الحركة `financial_transactions.id` الذي تستقبله الدالة بدل متغير غير معرّف ورقم الطلب.

## حدود الاختبار

- تم التحقق من بناء PHP للملفين المعدلين باستخدام `php -l`.
- لم يتم اختبار استعلامات قاعدة البيانات؛ ملف `inc/Databases/createDatabase.sql` لا يحتوي على تعريفات جداول النظام المحاسبي الجديد ولا الحقول `SALE_ENTRY_ID` و`RETURN_ENTRY_ID` و`accounting_posted` و`accounting_entry_id` التي يتوقعها الكود.
- لذلك لا يمكن اعتماد هذه النسخة على قاعدة تشغيل حقيقية قبل تزويدنا بتصدير بنية قاعدة البيانات الفعلية أو ملفات ترحيل المخطط المعتمدة.
- لا تزال إزالة `partners_balance` و`invoices` و`financial_transactions` غير منفذة؛ يجب تحويل جميع الصفحات والتقارير والإجراءات المخزنة أولًا.
