# المرحلة 30: تسوية الشحن غير المحصل وتعويض المندوب
- عند رفض العميل وعدم تحصيل الشحن لا تُرحّل عمولة تلقائية.
- تحفظ محاولة الرفض في قائمة مراجعة مع لقطة رسوم الشحن ونسبة المندوب والعمولة التقديرية.
- مسؤول المالية يستطيع اعتماد تعويض كامل أو جزئي لا يتجاوز التقديري، أو رفضه.
- الرفض لا ينشئ قيدًا ماليًا.
- الاعتماد فقط ينشئ قيدًا: مدين مصروف عمولة المندوب، دائن عمولة مستحقة للمندوب.
- البيع المباشر ORDER_TYPE_ID=5 مستثنى.
- shipmov_id هو مفتاح المحاولة ويمنع تكرارها.
- لم تنفذ Migration أو اختبارات قاعدة بيانات أو نشر.
