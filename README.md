# Just-M — Rebuild V2

إعادة بناء Just-M من الصفر باستخدام **Laravel 13 + PHP 8.4 + MariaDB** على فرع مستقل.

## الحالة الحالية

- تم تجهيز هيكل Laravel 13 الأساسي بالاعتماد على Laravel application skeleton الرسمي.
- لم تُنشأ بعد وظائف البيع أو المخزون أو الشحن أو الحسابات.
- لم يتم إنشاء migrations خاصة ببيانات العمل، ولم يتم الاتصال بأي قاعدة بيانات.
- لا يحتوي المستودع على ملف `.env` أو أسرار اتصال.
- المشروع القديم على `main` مرجع لاكتشاف السلوك، وليس مصدرًا للنسخ الأعمى.

## متطلبات التشغيل المحلية

- PHP 8.4 مع الامتدادات المطلوبة من Laravel، وبالأخص `pdo_mysql` و`mbstring` و`openssl` و`fileinfo`.
- Composer 2.
- Node.js مطلوب فقط عند إضافة وتجميع أصول الواجهة الأمامية.

## بدء التشغيل بعد استنساخ المستودع

```bash
composer install
cp .env.example .env
php artisan key:generate
```

عدّل إعدادات قاعدة البيانات محليًا عند بدء مرحلة قاعدة البيانات. لا تشغّل migrations على أي قاعدة حقيقية دون مراجعة واعتماد منفصل.

للتأكد من جاهزية Laravel:

```bash
php artisan about
php artisan route:list
```

## مبادئ التصميم

- تقسيم المجال إلى Domain وApplication وInfrastructure مع استخدام Laravel في HTTP وDI وValidation وDatabase وTesting.
- الأستاذ العام (General Ledger) هو مصدر الحقيقة المالي الوحيد.
- كل عملية مالية يجب أن تكون قابلة للتتبع وغير قابلة للترحيل المكرر.
- استخدام DECIMAL للمبالغ، ومعاملات قاعدة البيانات للعمليات المركبة.
- لا تُنقل قواعد العمل القديمة قبل توثيقها ومراجعتها واعتمادها.
- لا نشر ولا تعديل لقاعدة بيانات حقيقية من هذا الفرع.
