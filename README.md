# Just-M — Rebuild V2

إعادة بناء نظام Just-M باستخدام **Laravel 13 + PHP 8.4 + MariaDB** على فرع مستقل، مع مراجعة النظام القديم لاستخراج السلوك والقواعد الصحيحة دون نسخه آليًا.

## الحالة الحالية

المشروع تجاوز مرحلة الهيكل التأسيسي، ويحتوي حاليًا على:
- وحدة تهيئة قاعدة البيانات وإنشاء أول مستخدم إداري.
- تسجيل الدخول.
- إدارة المستخدمين ومجموعات الصلاحيات.
- Middleware للتحقق من الصلاحيات وسجل تدقيق لإجراءات إدارة الوصول.
- اختبارات Feature للتهيئة والمصادقة وإدارة الوصول.

**لم تكتمل بعد** وحدات المبيعات والمخزون والشحن والمرتجعات والمحاسبة والأستاذ العام. وجود التأسيس والصلاحيات لا يعني أن النظام التجاري مكتمل أو جاهز للإنتاج.

## متطلبات التشغيل

- PHP 8.4 مع الامتدادات اللازمة لـ Laravel، خصوصًا `pdo_mysql` و`mbstring` و`openssl` و`fileinfo`.
- Composer 2.
- MariaDB.
- Node.js فقط عند الحاجة إلى بناء أصول الواجهة الأمامية.

## التشغيل المحلي

```bash
composer install
cp .env.example .env
php artisan key:generate
```

اضبط بيانات قاعدة البيانات و`SETUP_TOKEN` في `.env` محليًا، ثم اتبع [دليل التهيئة](docs/SETUP_GUIDE_AR.md). لا ترفع `.env` أو مفاتيح التشفير أو كلمات المرور إلى Git.

## الاختبارات

```bash
php artisan test
```

راجع نتيجة CI للـ commit الحالي؛ لا تعتمد على نتيجة تشغيل قديمة لتقرير حالة HEAD الجديد.

## قواعد أساسية

- الأستاذ العام (General Ledger) هو مصدر الحقيقة المالي الوحيد.
- فصل ملكية بيانات المخزون عن القيود والأرصدة المالية.
- كل عملية مالية قابلة للتتبع ومحمية من الترحيل المكرر.
- المبالغ تستخدم DECIMAL، والعمليات المركبة تستخدم معاملات قاعدة البيانات.
- الصلاحيات تُفحص على الخادم، ولا تُمنح تلقائيًا بنوع الحساب أو المسمى.
- لا دمج إلى `main` أو نشر أو تعديل قاعدة بيانات فعلية دون طلب صريح.
