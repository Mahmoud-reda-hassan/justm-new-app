# Just-M Rebuild V2

إعادة بناء مشروع Just-M من الصفر على فرع مستقل، مع الاحتفاظ بالمشروع الحالي على `main` كمرجع تاريخي وتشغيلي.

## قواعد البناء

- PHP 8.4 وPDO، دون Framework إلزامي.
- فصل واضح بين Domain وApplication وInfrastructure وPresentation.
- قاعدة البيانات والتغييرات عليها تدار عبر migrations قابلة للتتبع.
- لا تُنقل قواعد العمل من النظام القديم قبل توثيقها ومراجعتها واختبارها.
- الأستاذ العام (General Ledger) هو مصدر الحقيقة المالي الوحيد في التصميم الجديد.
- لا يتم النشر أو تعديل قاعدة بيانات حقيقية من هذا الفرع.
- كل مرحلة لها اختبارات ومعايير قبول قبل الانتقال لما بعدها.
