Scope

- No database schema or production database changes.

Fixes and improvements
1. Product search now searches product name, product ID, category name/ID, and every nested product code in PRODUCT.CODES. The previous implementation searched PRO_CODE on the parent product record, but the API returns codes nested under CODES.
2. Category filters are rebuilt from the loaded product data, sorted by Arabic category name, safely escaped, and filter by CAT_ID.
3. Customer edit now returns to step 1, displays the edit form in its actual panel, and no longer hides the customer summary while leaving the user on the review step. Saving continues to preserve the selected product cart.
4. Replaced the product cart's table markup with responsive product cards showing image, product name, category, code, options, quantity, unit price, per-unit discount, line total, edit, and delete actions.
5. Added a custom 3D-style SVG fallback product image at img/product-default-3d.svg and wired storefront/product detail/cart fallbacks to it.
6. Refined Arabic typography, input readability, customer search/add/edit panels, product cards, cart cards, summary panels, colors, spacing, and mobile layout.
7. Added a fixed bottom taskbar containing all three order steps, previous/next navigation, and the existing save/cancel actions. Step shortcuts enforce the required customer/cart prerequisites.
8. Updated the NewOrder stylesheet cache version to 4.0.0.
