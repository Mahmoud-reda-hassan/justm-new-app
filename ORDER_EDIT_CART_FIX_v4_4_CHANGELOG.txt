Just-M - Order Edit / Product Cart Fix v4.4
Date: 2026-11-03
Base: just-m.net_newApp_customerFirst_UI_v4_3_orderLifecycle_03-11-2026.zip

Changes:
1. EditOrder now renders its products through the same card cart renderer used by NewOrder.
2. EditOrder now initializes the storefront product catalog, enabling product edit actions on existing orders.
3. The EditOrder loader writes the rendered cart into #itemorder instead of inserting legacy table rows before the removed #addPorduct row.
4. Product editing passes the original product code directly into the cart update routine; it no longer depends on the legacy SweetAlert #swl-productes element.
5. Editing the same product code adds the existing order quantity back to available stock before validating the edited quantity.
6. Product changes are logged safely, including option, quantity, discount, and product-code changes. Existing duplicate product codes are merged to preserve one cart line per code.
7. Save/cancel action buttons remain side by side on narrow screens to reduce bottom-bar height.
8. Bumped the storefront stylesheet query version to 4.4.0 to avoid stale browser CSS cache.
